# Security policy

Playwright Demo Recorder processes traces and live DOM snapshots that may
contain private application data. Please do not attach a real trace, generated
demo, session file, token, or screenshot to a public issue.

## Reporting a vulnerability

If this repository shows a **Security > Report a vulnerability** form, use it
to send a private report. Include a minimal synthetic reproduction, the
affected version, and the impact. Otherwise, open a public issue that asks the
maintainer to establish a private channel, without including sensitive details.

The maintainer will confirm receipt, assess the impact, and coordinate
disclosure after a fix is ready.

## Supported versions

The project has not published its first stable release. Security fixes target
the latest release and the current default branch.
